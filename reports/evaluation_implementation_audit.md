Sisi generasi dan retrieval (bagian 1–5) sebagian besar sudah sesuai. Ini mencakup sampler, pemisahan dev/test, exclusion per kueri di B/C/D termasuk *Duplicate* dua arah, paritas korpus B (725.795 vektor), konfigurasi generator, dan rumus trustScore v3. Celah utama ada di sisi pengukuran (bagian 7–10), yaitu judge, validasi manusia, probe bias, metrik, dan analisis, serta di matriks run resmi.

### Lima celah paling kritis untuk validitas hasil

1. **Judge halusinasi tidak melihat konteks retrieval (7.4, 7.5, 10.4, 10.6c).** judge-v2.1 hanya menerima pertanyaan, accepted answer, dan jawaban kandidat. Akibatnya *faithfulness* (B–D), `supported_by_context`, dan *citation support* tidak bisa dihitung seperti yang dirancang. Faithfulness kini hanya ada di judge lama (`llm_judge_hallucination.py`) sebagai skor 0–1 yang langsung dilaporkan judge.
2. **Jalur run resmi tidak menghasilkan ablasi α = 0 (6.1, 5.3, 5.4).** Preset *Official* di Factorial Batch membedakan C-uniform dan C-trust lewat `fusion_mode`, padahal pada C v3 `fusion_mode` diabaikan dan keempat run C memakai α yang sama. Akibatnya R6/R7 akan identik dengan R4/R5. Default CLI C juga masih `--c-retrieval-version v2`. `official_params.json` masih `pending_selection`, dan kandidat tahap 2 kini α ∈ {0,25; 0} (Amendment 9), sehingga α\* bisa saja 0.
3. **Kunci API yang tampak asli ada di riwayat git yang sudah di-push (11.2).** Commit `9a04681` dan `8f8f0cb` (2026-08-11, ada di `origin/master`) memuat `02_baseline_replication/.env` dengan nilai `OPENAI_API_KEY` (164 karakter) dan `ANTHROPIC_API_KEY` (108 karakter), bukan placeholder. Ini masalah keamanan, bukan validitas, tetapi harus ditangani pertama.
4. **Validasi judge belum siap dan berbeda dari desain (8.2–8.5, 7.8, 7.9).** Lembar anotasi kalibrasi masih kosong (0/60 dan 0/30 terisi). Lembar hanya berlabel tingkat jawaban, tanpa label per klaim, `approach_match`, `domain_familiarity`, atau kolom bukti. Set konfirmasi berisi 30 item dari run tahap 2, bukan 63 item (7 × 9 run). Belum ada bootstrap CI dan re-anotasi intra-annotator. judge-v2.1 belum pernah dijalankan dan belum dibekukan.
5. **Rantai analisis Bab V masih memakai rancangan lama (10.2, 10.9, 9.x).** `compare_conditions_stats.py` masih menghitung Wilcoxon + Holm + Cliff's δ di atas label 3-kelas judge lama. Interval Wilson belum ada di mana pun. Belum ada skrip tunggal untuk tabel Bab V, dan ketiga probe bias judge belum ada.
